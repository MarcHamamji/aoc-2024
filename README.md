# Advent of Code 2024 - Solutions
This repository contains my solutions for the [Advent of Code](https://adventofcode.com/) 2024 programming challenges. Each day's challenge is solved in a separate directory.

## Directory Structure
- `day-XX/main.rs`: Solution for day XX
- `day-XX/example.txt`: Example input file for day XX
- `day-XX/input.txt`: Input file for day XX *(different for each user)*
